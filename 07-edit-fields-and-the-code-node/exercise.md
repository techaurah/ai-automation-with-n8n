# Lesson 07: Exercise

## Split a fat node

1. Write (in the workflow) one deliberately fat Code node that does everything from this lesson at once: cleaning, urgency, summary, plus a new job: counting how many of the words in the message are longer than eight letters.
2. Now refactor it into the course shape: Edit Fields for hygiene, Code for judgement. Both versions must produce identical output on three test enquiries you invent, one of them urgent, one with a missing channel.
3. Note which version you would rather debug at midnight, and the specific reason.

You are done when both versions agree on all three enquiries and your note exists.
