# Lesson 23: Exercise

## The amnesia audit

1. With the window at its lesson setting, run a scripted twelve-exchange conversation in chat A that plants a fact in exchange 1 (a name) and a preference in exchange 6, then asks about both at exchange 12. Record what survives.
2. Repeat with the window halved. Record again.
3. Write the sizing rule you would ship for a front-desk agent (window size, and the reasoning in terms of real conversation shapes, not token prices alone).
4. Add one sentence to the agent's system message that handles discovered amnesia gracefully, and test that it triggers.

You are done when the audit table exists and the agent, when it has forgotten, says so like a professional instead of improvising.
