# Lesson 23: Solution notes

Survival is arithmetic: a fact survives to exchange 12 only if it sits inside the last N exchanges, so the audit is really a measurement of your conversation's shape. Front-desk chats are short and topical, so a modest window (5 to 10 exchanges) covers real needs; long advisory conversations argue for summarising memory patterns from Course 1 rather than a giant window, because cost grows linearly while recall quality does not. The graceful sentence is some version of: "I do not have that detail in front of me from earlier in our chat; could you confirm it?" Tested, it converts a memory limit from a hallucination risk into a moment of visible honesty, which customers read as competence.

**What to notice.** Memory bugs rarely crash anything. They erode trust one subtly wrong answer at a time, which is why this lesson's tests are behavioural (two chats, planted facts) rather than structural.
