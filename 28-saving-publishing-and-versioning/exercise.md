# Lesson 28: Exercise

## Rehearse a rollback

1. Import this lesson's workflow and publish it. POST a test order and confirm the response.
2. Make a breaking draft change (rename the response field), publish, and POST again to see the break.
3. Roll back using only the export you took before the break (import and publish), and POST a third time to prove recovery. Time the whole rollback.
4. Write the rollback steps into the workflow's notes as if for a colleague who has never seen this workflow.

You are done when recovery is proven, timed, and documented well enough to be done by someone else.
