## [1.0.0] - 2026-11-05

### Added

- Initial release of AI Automation with n8n: 35 lessons (00 to 34) in 8 modules, from setup and the items model through core nodes, real services, reliability, AI in n8n, and production, ending in the Lead Machine capstone.
- Every lesson ships as a complete unit: written lesson, importable workflow JSON validated in CI, a Python twin or checker where the logic is testable offline, one exercise, and a worked solution, with a zero-credential demo path throughout.
- Capstone: the Lead Machine (intake, qualification, follow-up, daily digest) for a fictional dental clinic, with a data model, a rubric exercise, a shipping gate, and a public showcase index for finished learner projects.
- Repository tooling: tools/validate_workflows.py (workflow JSON integrity, run in CI) and tools/check_links.py (relative link integrity), plus the per-lesson scanners in Lessons 13 and 30.
- PROGRESS.md learner checklist, curated resources shelf, a plain-language glossary, llms.txt course index for AI assistants, translation contribution structure, and the two-tier contribution rule (small fixes by PR, new lessons and translations by issue first).
- RESEARCH.md (the competitor scan this design answers) and DESIGN.md (title, audience, lesson map, capstone, visuals) kept in the repo as the course's design record.
