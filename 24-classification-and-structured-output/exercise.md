# Lesson 24: Exercise

## Measure, then tune

1. Write twenty short tickets of your own, five per category, including two deliberately ambiguous ones, and label them by hand before running anything.
2. Run them through the twin's rule classifier and the workflow's model classifier. Build the confusion table: where each classifier was wrong, and how.
3. Adjust one thing (a category description, or the confidence threshold) based on the table, rerun, and show the improvement or the honest lack of it.
4. Set the escalation threshold where your measured errors say it belongs, and write the reasoning in the workflow notes.

You are done when the confusion table exists, the threshold is measured rather than guessed, and both classifiers' remaining errors are the genuinely ambiguous tickets.
