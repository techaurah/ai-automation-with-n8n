# Lesson 01: Exercise

## Score your own backlog

1. List five tasks you or your team do repeatedly. For each, answer the three questions in writing: do the steps stay fixed, does any step need judgement, how many runs a month.
2. Run each through the logic of `decide.py` (extend the SCENARIOS list in your fork, or score by hand).
3. For the one task the test calls a workflow, sketch its path in words: trigger, steps, branches, final action. Name the input that would break your sketch.
4. For any task the test calls an agent's job, write the sentence that proves the steps cannot be fixed in advance. If you cannot write it, the task is not an agent's job.

You are done when all five tasks have a verdict with reasoning, and at least one verdict surprised you. If nothing surprised you, pick harder tasks.
