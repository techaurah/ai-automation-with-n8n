# Lesson 00: Exercise

## Make the setup decision, in writing

1. Run `check_environment.py` and save its output (copy it into a note in your fork, for example `my-setup.md` in this lesson folder of your fork).
2. Write three short paragraphs in that note. First: which way to run n8n you chose (self-hosted, Cloud, or npm demo for now) and the deciding reason. Second: where your workflow data will live, and how you would feel if it vanished tomorrow. Third: which optional cost, if any, you are accepting (a Cloud plan, hosted model usage, or none), with the figure you found on the pricing page today and the date you found it.
3. If your checker printed a FAIL, fix it now and rerun until it does not. If it printed WARN lines, your note should say why each one is acceptable for your chosen path.

You are done when the note exists, the checker is FAIL-free, and your future self could rebuild this setup from the note alone.
