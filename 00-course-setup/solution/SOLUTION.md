# Lesson 00: Solution notes

There is no single right setup; there are three defensible ones, and the exercise grades the reasoning, not the choice.

**Self-hosted in Docker** is the course default and the strongest default answer: free with no execution cap, every lesson works as written, and the production module (Lessons 29 to 31) is literally about this path. Its honest cost is operational: you own updates and backups.

**n8n Cloud** is right when the learner's time is worth more than the subscription and no client data policy forbids hosted automation. The note should name the trial end date and the plan the capstone would need, from the pricing page, not from a blog.

**npm demo** is only defensible as a two-week trial balloon with a written migration intention. A note that picks npm "because it was easiest" without naming the deprecation and the production warning has not done the exercise.

**What to notice.** Every later surprise in this course (a paywall, a lost workflow, a version difference) traces back to a setup decision made or skipped here. That is why the course spends a whole lesson on it.
