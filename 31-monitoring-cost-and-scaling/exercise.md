# Lesson 31: Exercise

## The estate review, performed once for real

1. Pull a week of executions from your own instance (the API skeleton, or the Executions view counted honestly) and compute the four numbers per workflow.
2. Write the one-page review: the outlier in each number, the decision each outlier earns (fix, watch, retire), and one automation you would not rebuild today, with its three-currency cost.
3. Set two thresholds from the data (not from imagination) that would page a review next week, and wire or simulate the digest check for them.

You are done when the review names a retirement candidate and defends it; an estate where everything earns its keep forever is an estate nobody has reviewed.
