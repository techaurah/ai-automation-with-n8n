# Visual guide

Every core idea in this course has a diagram. They are drawn in one
style so the shapes stay familiar: navy boxes are the main actor or
step, light boxes are supporting steps, amber boxes are gates where
a human or a safety check decides. Each diagram also lives inside
the lesson it belongs to.

| Diagram | What it teaches | Used in |
|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 8 modules, one arc, one capstone | README |
| [workflow-anatomy.svg](workflow-anatomy.svg) | Trigger, nodes, connections, executions: reading a workflow as a sentence | Lessons 01, 03 |
| [items-and-json.svg](items-and-json.svg) | A list of items in, a list out, one JSON object per item | Lesson 04 |
| [expressions-flow.svg](expressions-flow.svg) | Mapping fields with expressions, and the same-node boundary | Lesson 05 |
| [trigger-types.svg](trigger-types.svg) | Manual, schedule, webhook, form, and chat triggers, one house shape after each | Lesson 06 |
| [error-workflow.svg](error-workflow.svg) | Failure to error workflow to a human, with context | Lesson 17 |
| [ai-agent-anatomy.svg](ai-agent-anatomy.svg) | Agent root node with model, tools, and memory as sub-nodes | Lessons 20, 21 |
| [rag-pipeline.svg](rag-pipeline.svg) | Load, split, embed, store, retrieve, answer with citations | Lesson 25 |
| [mcp-directions.svg](mcp-directions.svg) | MCP Client Tool out, MCP Server Trigger in | Lesson 26 |
| [production-layers.svg](production-layers.svg) | Publish, hosting, security, monitoring: the layers around a workflow | Lessons 28 to 31 |
| [capstone-flow.svg](capstone-flow.svg) | The Lead Machine: intake, qualify, follow up, digest | Lessons 32 to 34 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py)
so the set stays consistent. Edit the script, rerun it, and commit
the SVGs it writes. Every use carries descriptive alt text, so
screen-reader learners and search engines get the same content as
sighted readers.
