# Assets

Shared images for this course live here: the README banner, diagrams reused across lessons, and social artwork.

The course diagram set lives in [visuals/](visuals/): one diagram per core idea, generated by a script so the style stays consistent, indexed in [visuals/VISUALS.md](visuals/VISUALS.md). Lesson-specific images live inside each lesson folder next to the lesson that uses them; only artwork shared by the whole course (banner, series diagrams) belongs here. Name files in kebab-case and always add descriptive alt text where an image is used, so screen-reader learners and search engines get the same content as sighted readers.
