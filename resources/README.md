# Resources

Curated resources for AI Automation with n8n, grouped by theme.
Lessons link to the items they use; this page is the full shelf.
Official documentation first, because it ages best. If a link here
breaks, that is a lesson problem: please open an issue so it gets
fixed for everyone.

New to a word? The [glossary](glossary.md) defines every term this
course uses, in plain language.

## Official n8n

- [n8n documentation](https://docs.n8n.io): the single source of
  truth for every node, setting, and hosting question in this course.
- [n8n Academy](https://learn.n8n.io): n8n's own free courses
  (Quickstart and the Foundations programme), with exams and badges.
  This course is the repository-native companion to them, not a
  replacement.
- [n8n workflow templates](https://n8n.io/workflows/): the official
  template library; read templates the way Lessons 22 and 30 teach
  (catalogue review, vet before you import).
- [n8n community forum](https://community.n8n.io): workflow help,
  node questions, and the community's accumulated debugging lore.
- [n8n GitHub repository](https://github.com/n8n-io/n8n): the source,
  releases, and breaking-change notes the update drill reads.
- [Self-hosted AI starter kit](https://github.com/n8n-io/self-hosted-ai-starter-kit):
  n8n plus Ollama plus a vector store in Docker, Module 5's local stack.

## AI building blocks

- [Model Context Protocol documentation](https://modelcontextprotocol.io):
  the specification behind Lesson 26, both directions.
- [Ollama](https://ollama.com): the local model runner the AI module
  defaults to, so no lesson needs a paid key.
- [LangChain documentation](https://python.langchain.com/docs): the
  framework n8n's AI nodes express visually; useful when you want
  the same concepts in code.
- [Agentic AI for Beginners](https://github.com/techaurah/agentic-ai-for-beginners):
  Course 1 of this programme; agents in depth, including evaluation,
  security, and the sister capstone.

## Practice APIs and tools

- [JSONPlaceholder](https://jsonplaceholder.typicode.com): the free
  fake API used by the HTTP and pagination lessons; no key, no signup.
- [Python documentation](https://docs.python.org/3/): the standard
  library every twin and checker in this course is built on.
- [Docker documentation](https://docs.docker.com): for the install
  and production stacks in Lessons 02 and 29.
- [PostgreSQL documentation](https://www.postgresql.org/docs/): the
  production database from Lesson 29.
